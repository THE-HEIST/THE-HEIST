📄 update/mark_as_done.py

📁 StudySmart/src/core/update/mark_as_done.py

🔍 What does this file do?

This file provides two functions: mark_completed() to mark an assignment as done, and undo_mark_as_done() to reverse that action. Both show the list of assignments first, then ask the user to pick one by its ID number.

📝 Full Source Code

from src.data_processing_module.config import Assignments from src.core.read.assignments import view_assignments def mark_completed(Assignments=Assignments, assignments=None): if assignments is None or len(assignments) == 0: print("\nNo assignments to update.\n") return view_assignments(assignments=assignments) user_input = input("\nEnter the assignment number to mark as completed: ") if not user_input.isdigit(): print("\nInvalid selection. Please choose a valid assignment number.\n") return selected_number = int(user_input) ass = Assignments.find("assignments", "id", selected_number) if (selected_number >= 0 and ass is not None and ass['completed'] == False): Assignments.update("assignments", "id", selected_number, {"completed": True}) print("\nAssignment marked as completed.\n") else: print("\nInvalid selection. Please choose a valid assignment number.\n") def undo_mark_as_done(Assignments=Assignments, assignments=None): if assignments is None or len(assignments) == 0: print("\nNo assignments to update.\n") return view_assignments(assignments=assignments) user_input = input("\nEnter the assignment number to undo mark as completed: ") if not user_input.isdigit(): print("\nInvalid selection. Please choose a valid assignment number.\n") return selected_number = int(user_input) ass = Assignments.find("assignments", "id", selected_number) if (selected_number >= 0 and ass is not None and ass['completed'] == True): Assignments.update("assignments", "id", selected_number, {"completed": False}) print("\nAssignment marked as not completed.\n") else: print("\nInvalid selection. Please choose a valid assignment number.\n")

📖 Key Parts Explained

Guard Clause (Early Return)

if assignments is None or len(assignments) == 0: — This checks if there are any assignments to work with. If not, it prints a message and returns immediately. This prevents errors from trying to show an empty list.

Input Validation with .isdigit()

user_input.isdigit() checks if the user typed a valid number (not letters or symbols). If they type "abc", it shows an error instead of crashing.

Three-Condition Check

if selected_number >= 0 and ass is not None and ass['completed'] == False:

Three things must be true to mark as done:

1. The number must be non-negative

2. An assignment with that ID must exist

3. The assignment must NOT already be completed

For undo_mark_as_done, condition 3 is reversed: ass['completed'] == True

Assignments.update()

Uses LangaDB's update() method to change the "completed" field from False to True (or vice versa), then saves to disk.
