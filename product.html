🔍 What does this file do?

This is the main controller of the entire application. It contains the main() function that displays the menu, handles user input, and routes to the correct feature. It's like a switchboard operator — it takes your request and connects you to the right department.

📖 Line-by-Line Explanation

Lines 1-5: Imports

Imports all the functions needed to handle the menu options. This is like gathering all the tools before starting work.

Lines 7-10: check_priority_new_day()

Called once when the program starts. It recalculates all assignment priority scores based on today's date. Without this, scores from yesterday would be wrong because one more day has passed.

Lines 12-17: print_menu()

A helper function that formats and prints a numbered menu. Takes a list of (number, name) tuples and displays them neatly.

Lines 19-32: view_func()

Handles the "View Assignments" submenu. Shows three options (Undone/Done/All), gets the user's choice, and calls the appropriate function to filter and display assignments.

Lines 34-36: clear_terminal()

Clears the terminal screen. Uses 'cls' on Windows and 'clear' on Mac/Linux. os.name == 'nt' checks if the operating system is Windows.

Lines 38-66: main()

The main loop of the entire application:

1. check_priority_new_day() — Recalculates priorities first

2. while True: — Creates an infinite loop that keeps showing the menu

3. Displays the menu and asks for user input

4. Routes to the correct function based on the choice (1-7 or 0)

5. Choice 0 breaks the loop and exits

6. try/except ValueError — Catches invalid input (if user types text instead of a number)

This is the heart of the application — it runs forever until the user chooses to exit.
