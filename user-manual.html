📖 User Manual

A complete guide to using every feature of StudySmart.

🎮 Main Menu Overview

When you start the application, you see the main menu. Each number corresponds to a feature:

No Function Name --------------------------------------------- 1 View Assignments 2 Add Assignment 3 Mark Assignment as Done 4 Undo Mark Assignment as Done 5 Show Study Summary 6 Clear Terminal 0 Exit

Type the number of the feature you want and press Enter. Type 0 to exit the program.

➕ Adding an Assignment (Option 2)

Choose option 2 from the main menu. You will be asked to enter details about your assignment:

Assignment name: Math Homework Module: Algebra Deadline (Ex: yyyy-mm-dd): 2026-09-15 Difficulty level (1 to 5): 3

Fields explained:

→ Assignment name: A short name for your task (e.g., "Math Homework", "Essay Draft")

→ Module: The subject or course it belongs to (e.g., "Algebra", "History")

→ Deadline: When it's due, in the format YYYY-MM-DD (e.g., 2026-09-15)

→ Difficulty level: How hard it is, from 1 (easy) to 5 (very hard)

💡 Important Notes

→ The name, module, and deadline fields cannot be left empty.

→ The difficulty must be a number between 1 and 5.

→ The deadline must be in the format YYYY-MM-DD (e.g., 2026-12-31).

→ After adding, the assignment is automatically assigned a priority score.

What happens behind the scenes:

When you add an assignment, the program:

1. Checks that all fields are valid (not empty, correct format)

2. Calculates a priority score: score = difficulty / (days_remaining + 1)

3. Assigns a priority level: HIGH, MEDIUM, LOW, or OVERDUE

4. Saves the assignment to the JSON database file

📋 Viewing Assignments (Option 1)

Choose option 1 to view your assignments. You get three sub-options:

No Function Name --------------------------------------------- 1 View Undone Assignments 2 View Done Assignments 3 View All Assignments

Each option shows a table with these columns:

ID Assignment Name Module Deadline Difficulty Score Completed ------------------------------------------------------------------------------------------ 1 Math Homework Algebra 2026-09-15 3 1.00 Not Done 2 Essay Draft English 2026-09-20 4 0.80 Done 3 Lab Report Physics 2026-09-10 5 2.50 Not Done

Column meanings:

→ ID: A unique number for each assignment (auto-assigned)

→ Score: The priority score (higher = more urgent)

→ Completed: "Done" or "Not Done"

Assignments are sorted by score in descending order (most urgent first).

✅ Marking an Assignment as Done (Option 3)

Choose option 3 to mark an assignment as completed:

# First, view undone assignments ID Assignment Name Module Deadline Difficulty Score Completed ------------------------------------------------------------------------------------------ 1 Math Homework Algebra 2026-09-15 3 1.00 Not Done # Enter the assignment number to mark as completed Enter the assignment number to mark as completed: 1 # Result Assignment marked as completed.

Enter the ID number of the assignment you want to mark. Only undone assignments can be marked.

↩ Undo Marking as Done (Option 4)

Choose option 4 to undo a completed assignment (mark it as not done again):

# View done assignments ID Assignment Name Module Deadline Difficulty Score Completed ------------------------------------------------------------------------------------------ 2 Essay Draft English 2026-09-20 4 0.80 Done # Enter the assignment number to undo Enter the assignment number to undo mark as completed: 2 # Result Assignment marked as not completed.

📊 Study Summary (Option 5)

Choose option 5 to see your progress statistics:

Total assignments: 5 Completed: 2 Incomplete: 3 Completion rate: 40.0%

This shows how many assignments you've completed vs. how many are still pending.

🎯 How the Priority System Works

StudySmart automatically calculates how urgent each assignment is using a formula:

# The priority formula priority_score = difficulty / (days_remaining + 1) # Example: Hard assignment (5) due tomorrow (1 day left) score = 5 / (1 + 1) = 2.5 → HIGH # Example: Easy assignment (2) due in 10 days score = 2 / (10 + 1) = 0.18 → LOW

Priority Levels:

→ HIGH — Score ≥ 2 (urgent, do this first!)

→ MEDIUM — Score between 1 and 2

→ LOW — Score < 1 (still have time)

→ OVERDUE — Score = 99999 (deadline has passed!)

⚠ Recalculation

The priority scores are automatically recalculated every time you start the program. This ensures the scores reflect the current date.

💾 Where is my data saved?

All your data is saved in JSON files inside the src/data/ folder:

→ users.json — Stores your account (username + encrypted password)

→ assignments.json — Stores all your assignments

→ session.txt — Stores who is currently logged in

💡 Tip

Don't delete these files unless you want to start fresh. They contain all your data!

⌨ Input Tips

→ Always press Enter after typing your input.

→ Use numbers (not words) to select menu options.

→ Dates must be in format YYYY-MM-DD (e.g., 2026-12-31).

→ Difficulty must be a whole number from 1 to 5.

→ If you type something invalid, the program will ask you to try again.

→ Use option 6 (Clear Terminal) to clean up your screen.
