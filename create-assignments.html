🔍 What does this file do?

This file handles adding new assignments to the system. It collects all the details from the user (name, module, deadline, difficulty), validates the input, calculates the priority score, and saves the assignment to the database. It includes robust input validation — empty fields are rejected, invalid dates are caught, and difficulty must be 1-5.

📖 Key Parts Explained

Input Collection with Validation

Each field uses a while loop that keeps asking until a non-empty value is provided. This is a simple but effective way to ensure no field is left blank.

Pattern: Ask → Check if empty → If empty, show error and ask again

Difficulty Validation (try/except)

int(input(...)) is wrapped in try/except ValueError. If the user types "abc" instead of a number, Python would crash. The except catches this and returns error code 400.

Date Validation

datetime.strptime(deadline, "%Y-%m-%d") tries to parse the date. If the format is wrong (e.g., "31-12-2024" instead of "2024-12-31"), it raises a ValueError which is caught.

Building the Assignment Dictionary

Creates a dictionary with all the fields, then calculates the priority score and level before saving. The assignment starts with "completed": False (not done yet).

Return Codes

→ return 200 — Success (like HTTP 200 OK)

→ return 400 — Bad input (like HTTP 400 Bad Request)

These codes let the caller (tests) know if the operation succeeded or failed.
