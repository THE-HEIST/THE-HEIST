📄 auth/session.py

📁 StudySmart/src/core/authentication/session.py

🔍 What does this file do?

This file manages login sessions — it remembers who is currently logged in. When a user logs in, their username is saved to a text file (session.txt). When they log out, that file is emptied. When the program starts, it reads this file to check if someone is already logged in.

Note: This file has some duplicate code at the bottom (an older version of the same functions). The active code is the first set of functions that use BASE_DIR.

📝 Full Source Code

from pathlib import Path from src.data_processing_module.config import Users from src.data_processing_module.config4test import test_users_db as TestUsers BASE_DIR = Path(__file__).resolve().parent.parent.parent.parent def save_session(username: str, test=None): SESSION_FILE = BASE_DIR / 'src' / "data" / "session.txt" if test is not None: SESSION_FILE = BASE_DIR / 'src' / "data" / test SESSION_FILE.write_text(username, encoding="utf-8") def load_session(Users=Users, test=None): SESSION_FILE = BASE_DIR / 'src' / "data" / "session.txt" if test is not None: SESSION_FILE = BASE_DIR / 'src' / "data" / test Users = TestUsers if not SESSION_FILE.exists(): return None username = SESSION_FILE.read_text(encoding="utf-8").strip() if not username: return None return Users.find("users", "username", username) def clear_session(Users=Users, test=None): SESSION_FILE = BASE_DIR / 'src' / "data" / "session.txt" if test is not None: SESSION_FILE = BASE_DIR / 'src' / "data" / test if SESSION_FILE.exists(): SESSION_FILE.write_text("", encoding="utf-8")

📖 Line-by-Line Explanation

Lines 1-3: Imports

→ Path — For building file paths

→ Users — The real user database

→ TestUsers — The test user database (aliased to avoid name collision)

Line 5: BASE_DIR

BASE_DIR = Path(__file__).resolve().parent.parent.parent.parent

Goes up 4 levels from session.py to reach the project root: authentication/ → core/ → src/ → StudySmart/

Lines 7-10: save_session()

Saves the logged-in username to session.txt. If test is provided, it saves to the test session file instead.

SESSION_FILE.write_text(username) — Writes the username string directly to the file.

Lines 12-19: load_session()

Reads the session file to find who's logged in:

1. If file doesn't exist → returns None (no session)

2. Reads the username from the file, strips whitespace

3. If empty → returns None

4. Otherwise, looks up the user in the database and returns their data

Lines 21-25: clear_session()

Empties the session file by writing an empty string. This effectively "logs out" the user.

⚠ Duplicate Code Note

The file has duplicate function definitions at the bottom (an older version without the test parameter). Python will use the last definition it sees, but in this case the imports at the top of the file use the first definition. This is a known issue in the student code — the duplicate should ideally be removed.
