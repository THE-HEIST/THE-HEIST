📄 pyproject.toml

📁 StudySmart/pyproject.toml

🔍 What does this file do?

This file configures pytest (the testing framework). Specifically, it tells pytest to add the project root directory to Python's path so that imports like from src.core... work correctly during testing.

📝 Full File Content

[tool.pytest.ini_options] pythonpath = ["."]

📖 Line-by-Line Explanation

[tool.pytest.ini_options]

This is a TOML section header. TOML is a configuration file format (like JSON but more human-readable). This section configures pytest's options.

pythonpath = ["."]

This tells pytest to add the current directory ("." means "this folder") to Python's import path.

Why is this needed? When pytest runs tests, it needs to find modules like src.core.create.assignments. Without this setting, Python wouldn't know where to find the src folder because pytest changes the working directory.

Analogy: It's like telling the delivery driver "the package should be dropped off at the front door (current directory), not somewhere else."
