📁 Directory Structure

📄 config.py

📁 StudySmart/src/data_processing_module/config.py

🔍 What does this file do?

This is the configuration file that creates the two main database instances for the application: Users (for storing user accounts) and Assignments (for storing assignments). It's like the "settings page" that tells the program where to find and save data.

📝 Full Source Code

from pathlib import Path from src.LangaDB.controllers import LangaDB DATA_DIRECTORY = Path(__file__).resolve().parent.parent / "data" Users = LangaDB(db_path=str(DATA_DIRECTORY/"users.json"), default_data={"users": []}) Assignments = LangaDB(db_path=str(DATA_DIRECTORY/"assignments.json"), default_data={"assignments":[]})

📖 Line-by-Line Explanation

Line 1: Import Path

from pathlib import Path

Path is a Python class for working with file paths in a way that works on all operating systems (Windows, Mac, Linux). Instead of writing paths with slashes manually, Path handles it automatically.

Line 2: Import LangaDB

from src.LangaDB.controllers import LangaDB

Imports the LangaDB class we just learned about. This is the database engine that will handle all data storage.

Line 4: Finding the Data Directory

DATA_DIRECTORY = Path(__file__).resolve().parent.parent / "data"

This line finds the folder where data files are stored. Let's break it down step by step:

→ Path(__file__) — Gets the path of this current file (config.py), which is something like src/data_processing_module/config.py

→ .resolve() — Converts it to a full absolute path

→ .parent — Goes up one level: src/data_processing_module/

→ .parent — Goes up one more level: src/

→ / "data" — Adds "data" to the path: src/data/

Result: DATA_DIRECTORY points to the src/data/ folder.

Line 6: Creating the Users Database

Users = LangaDB(db_path=str(DATA_DIRECTORY/"users.json"), default_data={"users": []})

Creates a LangaDB instance for user data:

→ db_path — Points to src/data/users.json

→ default_data={"users": []} — If the file is empty or doesn't exist, start with an empty list of users.

→ str(...) — Converts the Path object to a string because LangaDB expects a string.

The Users variable is then imported by other files to save and load user accounts.

Line 7: Creating the Assignments Database

Assignments = LangaDB(db_path=str(DATA_DIRECTORY/"assignments.json"), default_data={"assignments":[]})

Same thing, but for assignments. Points to src/data/assignments.json with a default of empty assignments list.

📊 Data Flow

config.py sits in the middle — it creates database objects that many other files import:

→ imports Users to look up accounts

→ create/assignments.py imports Assignments to save new assignments

→ product.py imports Assignments for the main menu

→ read/assignments.py imports Assignments to load and display data
