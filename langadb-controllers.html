🔍 What does this file do?

This is the heart of the data storage system. It defines the LangaDB class — a custom, lightweight database engine built entirely in Python using JSON files. Instead of using a real database like MySQL or SQLite, this project stores all data as simple JSON files on disk.

The LangaDB class provides all the essential database operations: open, read, write, find, add, update, delete, sort, and query. Every other file in the project uses LangaDB to save and retrieve data.

Analogy: LangaDB is like a filing cabinet. You can put files in it (add), take files out (find), update files (update), throw files away (clear), and list all files (all).

📖 Line-by-Line Explanation

Lines 1-2: Imports

import json import os

json — A built-in Python library for reading and writing JSON data. JSON is a text format that looks like: {"name": "value"}. It's used to save/load data.

os — A built-in Python library for interacting with the operating system. Here it's used to check if a file exists using os.path.exists().

Lines 4-7: The Constructor (__init__)

class LangaDB: def __init__(self, db_path, default_data): self.db_path = db_path self.data = default_data if default_data is not None else {} self.open()

class LangaDB: — Defines a new "blueprint" called LangaDB. A class is like a template for creating objects.

__init__ — This is called a "constructor". It runs automatically when you create a new LangaDB object. Think of it like a setup routine.

db_path — The file path where data is stored (e.g., "src/data/users.json").

default_data — What to start with if the file is empty (e.g., {"users": []}).

self.db_path = db_path — Saves the file path for later use. self means "this particular object".

self.data = default_data if default_data is not None else {} — Sets the data to the default if provided, otherwise starts with an empty dictionary {}.

self.open() — Immediately tries to open and read the JSON file.

Lines 9-24: open() Method

def open(self): if not os.path.exists(self.db_path): try: with open(self.db_path, 'x', encoding='utf-8') as file: file.write("[]" if isinstance(self.data, list) else "{}") except Exception as e: print(f"Error: {e}") return False else: try: with open(self.db_path, 'r', encoding='utf-8') as file: self.data = json.loads(file.read()) except json.JSONDecodeError: print("Error: The files format was not JSON") return False

This method has two paths:

If the file does NOT exist: It creates a new file (using mode 'x' which means "create exclusively") and writes an empty JSON structure ("[]" for lists or "{}" for dictionaries).

If the file DOES exist: It opens the file (using mode 'r' for "read") and loads the JSON content into self.data using json.loads() which converts a JSON string into a Python object.

try/except — Error handling. If something goes wrong (e.g., file is corrupted), it prints an error message instead of crashing.

with open(...) as file: — The with statement automatically closes the file when done, even if an error occurs.

Lines 26-31: all() Method

def all(self, name): if isinstance(self.data, dict): return self.data.get(name, []) elif isinstance(self.data, list): return self.data else: return []

Returns all items from the database.

→ If data is a dictionary: returns the list under the given key (e.g., data["assignments"]).

→ If data is a list: returns the entire list directly.

→ If neither: returns an empty list [].

isinstance() checks what type something is. .get(name, []) gets a value from a dictionary, returning [] if the key doesn't exist.

Lines 33-39: save() Method

def save(self, new_data): try: with open(self.db_path, 'w', encoding='utf-8') as file: json.dump(new_data, file, ensure_ascii=False, indent=4) return True except Exception as e: print(f"Error: {e}")

Saves all data back to the JSON file.

open(..., 'w') — Opens the file in "write" mode, which overwrites the entire file.

json.dump(new_data, file, ...) — Converts the Python data into JSON text and writes it to the file. indent=4 makes the JSON pretty-printed (easy to read).

ensure_ascii=False — Allows non-English characters (like Vietnamese) to be saved.

Returns True on success, or prints an error on failure.

Lines 41-49: query() Method

def query(self, path, default=None): keys = path.split('.') current = self.data for key in keys: if isinstance(current, dict) and key in current: current = current[key] else: return default return current

Lets you navigate deep into nested data using a dot-separated path.

path.split('.') — Splits a string like "users" or "a.b.c" into a list: ["users"] or ["a", "b", "c"].

Then it walks through each key, going deeper into the data structure.

Example: If data = {"users": [{"name": "Tom"}]}, then query("users") returns [{"name": "Tom"}].

Lines 51-56: find() Method

def find(self, list_key, field_name, value): items = self.data if isinstance(self.data, list) else self.query(list_key, []) if isinstance(items, list): for item in items: if isinstance(item, dict) and item.get(field_name) == value: return item return None

Finds one specific item in the list by matching a field value.

Example: find("users", "username", "Tom") searches through all users and returns the first one where username == "Tom".

→ Gets the list of items (either directly from self.data or via query()).

→ Loops through each item, checking if the specified field matches the value.

→ Returns the first matching item, or None if nothing is found.

Lines 58-63: auto_increment_id() Method

def auto_increment_id(self, counter_key="last_id"): current = self.data.get(counter_key, 0) if isinstance(self.data, dict) else 0 new_id = current + 1 if isinstance(self.data, dict): self.data[counter_key] = new_id return new_id

Generates a unique ID number for each new item (like a serial number).

→ Reads the current last_id from data (starts at 0).

→ Adds 1 to get the new ID.

→ Saves the new ID back to data so the next call gets a different number.

Example: First call returns 1, second returns 2, third returns 3, etc.

Lines 65-73: add() Method

def add(self, list_key, new_item, auto_id=True): if auto_id and isinstance(new_item, dict) and "id" not in new_item: new_item["id"] = self.auto_increment_id() target = self.query(list_key) if isinstance(target, list): target.append(new_item) elif self.data == [] or isinstance(self.data, list): self.data.append(new_item) return self.save(self.data)

Adds a new item to the database.

→ If auto_id=True and the item doesn't already have an id, it automatically assigns one using auto_increment_id().

→ Finds the target list using query() and appends the new item.

→ Saves everything back to the file.

Example: add("assignments", {"name": "Math HW"}) adds a new assignment with an auto-generated ID.

Lines 75-80: sort_by() Method

Sorts items by a specific field. Used to sort assignments by score (priority).

sorted(items, key=lambda item: item.get(sort_key, 0), reverse=reverse) — Python's built-in sort. The lambda is a tiny function that extracts the sort key from each item.

reverse=True means highest values first. limit restricts the number of results returned.

Lines 82-86: update() Method

Finds an item by field name/value and updates its fields.

item.update(updates) — Merges the new values into the existing item. For example, if item = {"completed": False} and updates = {"completed": True}, after update the item becomes {"completed": True}.

Lines 88-97: clear_all() Method

Empties an entire list and resets the ID counter.

→ If data is a dictionary: sets the list to [] and last_id to 0.

→ If data is a list: clears the entire list.

Used in tests to start with a clean slate.

Lines 99-105: get_last_id() Method

Returns the last assigned ID number without incrementing it. Useful for knowing how many items exist.
