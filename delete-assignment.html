📄 delete/assignment.py

📁 StudySmart/src/core/delete/assignment.py

🔍 What does this file do?

This file handles deleting assignments from the system. It shows the list of assignments, asks the user to pick one by ID, and removes it from the database.

⚠ Note: This function calls Assignments.delete(), but the LangaDB class does not currently have a delete() method. This means the delete feature is not fully implemented — it would cause a runtime error if called. The function is also not connected to the main menu in product.py.

📝 Full Source Code

from src.core.read.assignments import view_assignments from src.data_processing_module.config import Assignments def delete_assignment(Assignments=Assignments, assignments=None): if assignments is None or len(assignments) == 0: print("\nNo assignments to delete.\n") return view_assignments(assignments=assignments) user_input = input("\nEnter the assignment number to delete: ") if not user_input.isdigit(): error_message = "\nInvalid selection. Please choose a valid assignment number.\n" print(error_message) return selected_number = int(user_input) ass = Assignments.find("assignments", "id", selected_number) if (selected_number >= 0 and ass is not None): Assignments.delete("assignments", "id", selected_number) print("\nAssignment deleted successfully.\n") else: error_message = "\nInvalid selection. Please choose a valid assignment number.\n" print(error_message)

📖 Line-by-Line Explanation

Structure Overview

Follows the same pattern as mark_completed():

1. Check if there are assignments to delete

2. Show the list of assignments

3. Ask user to pick an ID number

4. Validate the input

5. Find the assignment and delete it

Assignments.delete() — The LangaDB Method

Assignments.delete("assignments", "id", selected_number) — This line calls the delete() method on the LangaDB object. The method is defined in LangaDB/controllers.py and works by:

1. Getting the list of items from the database

2. Looping through each item with its index number

3. Checking if the item's field matches the value (e.g., id == selected_number)

4. If found, removing it from the list using del items[i]

5. Saving the updated data back to the JSON file

If no matching item is found, it returns False.
