🔍 What does this file do?

This file contains unit tests for the add_assignment() function. It tests 5 scenarios: successful creation, invalid difficulty, empty fields, invalid date format (two variations). It uses monkeypatch to simulate user input.

🧪 Testing Concepts Used

monkeypatch — A pytest feature that replaces built-in functions. Here it replaces input() so tests don't need real user interaction. Instead of typing, the test provides a list of pre-set answers.

assert — Checks if something is true. If not, the test fails.

Clear before each test — Assignments.clear_all("assignments") ensures each test starts with a clean database.

📝 Test Cases

test_add_assignment — Happy Path

Provides valid inputs: name="Test Assignment", module="Test Module", deadline="2024-12-31", difficulty="3". Expects return True (success) and verifies the assignment was saved.

test_add_assignment_invalid_difficulty

First tries difficulty "6" (too high), then "0" (too low), then "3" (valid). Tests that the validation loop correctly rejects invalid values and accepts valid ones.

test_add_assignment_empty_fields

Sends empty strings for name and module (which trigger the "cannot be empty" loops), then provides an empty string for deadline (which triggers the ValueError in date parsing). Expects return False because the empty deadline causes a ValueError in datetime.strptime().

test_add_assignment_invalid_deadline / invalid_deadline_format / invalid_deadline_format2

Tests three wrong date formats: "31-12-2024" (DD-MM-YYYY), "2024/12/31" (slashes), and "2024-31-12" (swapped month/day). All should be rejected with return False.
