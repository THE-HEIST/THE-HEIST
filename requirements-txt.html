📁 StudySmart/requirements.txt

🔍 What does this file do?

This file lists all the Python packages that need to be installed for the project to work. When you run pip install -r requirements.txt, pip reads this file and installs each package listed here.

📝 Full File Content

pytest pytest-cov requests

📖 Package Explanations

pytest

A popular Python testing framework. It makes it easy to write and run tests. The project uses pytest to run all unit tests in the tests/ folder. You run tests with pytest or pytest tests/.

pytest-cov

An extension for pytest that measures code coverage — what percentage of your code is executed by the tests. Run with pytest --cov=src to see a coverage report. This helps identify untested code.

requests

A library for making HTTP requests (web API calls). While it's not directly used in the current application code, it may be planned for future features or used in tests.

How to Use This File

Run this command to install all packages:

pip install -r requirements.txt

This is equivalent to running pip install pytest pytest-cov requests individually.
