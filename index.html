⬛ StudySmart _

A terminal-based assignment management system for students.
Built with Python, powered by a custom JSON database engine (LangaDB).
Manage your assignments, track priorities, and crush your deadlines!

▶ PLAY

★ Features

📋 CRUD Operations

Create, Read, Update, Delete assignments with full validation.

🎯 Smart Priority

Automatic priority scoring based on difficulty and deadline.

🔐 User Auth

Sign up, Log in, Session management with password hashing. ⚠️ NOT USED

📊 Study Summary

View completion rate and track your progress over time.

💾 LangaDB

Custom JSON-based database with auto-increment IDs.

✅ CI/CD

GitHub Actions testing across Python 3.9 - 3.13.

◆ Architecture

◈ Tech Stack

Python 3.9+

Core language for the entire application.

JSON

Pytest

Unit testing framework with monkeypatch.

SHA-256

Password hashing for user authentication. ⚠️ Not used in current version.
