🔍 What does this file do?

Tests the mark_completed() and undo_mark_as_done() functions. Verifies that the completed field is correctly toggled between True and False.

📝 Test Cases

test_mark_completed

1. Clears the database

2. Adds a test assignment with completed: False

3. Simulates user typing "1" (selecting assignment ID 1)

4. Calls mark_completed()

5. Verifies that after the call, completed == True

test_undo_mark_as_done

1. Clears the database

2. Adds a test assignment with completed: True

3. Simulates user typing "1"

4. Calls undo_mark_as_done()

5. Verifies that after the call, completed == False

Key Pattern: monkeypatch for Input

inputs = iter(["1"]) # Create an iterator with one value monkeypatch.setattr('builtins.input', lambda _: next(inputs))

This replaces Python's built-in input() function. Every time the code calls input(), it instead gets the next value from the iterator. lambda _: creates a function that ignores the prompt parameter and just returns the next value.
