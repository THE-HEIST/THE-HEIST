🔍 What does this file do?

This file tests the view_assignments() function — it verifies that assignments are correctly filtered (undone, done, all) and displayed with the right data in the output.

📝 Test Cases

capsys — Capturing Output

All tests use pytest's capsys fixture. This captures everything printed to the screen during the test. After calling the function, capsys.readouterr().out gives you the printed output as a string, which you can then check with assert.

test_view_assignments_undone

Creates 3 undone assignments, calls view_order_by_undone(), then verifies all three names appear in the output. Confirms the filtering logic only shows undone items.

test_view_assignments_done

Creates 3 done assignments, calls view_order_by_done(), verifies all three names appear. Confirms the done-only filter works.

test_view_assignments_all

Creates 3 assignments (2 undone, 1 done), calls view_order_all(), verifies all three names appear. Confirms the "show all" function includes both done and undone.
