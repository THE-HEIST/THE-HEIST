🔍 What does this file do?

This file handles viewing and displaying assignments. It provides functions to filter assignments (done, undone, or all), sort them by priority, display them as a formatted table, and show a study summary with completion statistics.

📝 Full Source Code

from src.data_processing_module.config import Assignments def view_order_by_undone(Assignments=Assignments, sort_key="score", reverse=True): assignments = Assignments.all('assignments') a = [] for i in assignments: if i.get("completed") == False: a.append(i) return sorted(a, key=lambda x: x.get(sort_key, 0), reverse=reverse) def view_order_by_done(Assignments=Assignments, sort_key="score", reverse=True): assignments = Assignments.all('assignments') a = [] for i in assignments: if i.get("completed") == True: a.append(i) return sorted(a, key=lambda x: x.get(sort_key,0),reverse=reverse) def view_order_all(Assignments=Assignments, sort_key="score", reverse=True): assignments = Assignments.all('assignments') return sorted(assignments, key=lambda x: x.get(sort_key,0), reverse=reverse) # ========================================== # FUNCTION 2: VIEW ASSIGNMENT # ========================================== def view_assignments(Assignments=Assignments, assignments=None): if assignments is None or len(assignments) == 0: print("No assignments found") else: header = ["ID", "Assignment Name", "Module", "Deadline", "Difficulty", "Score", "Completed"] print("{:<5} {:<20} {:<15} {:<12} {:<15} {:<8} {:<10}".format(*header)) print("-" * 90) for assignment in assignments: row = [ assignment.get("id", ""), assignment.get("assignment_name", ""), assignment.get("module_name", ""), assignment.get("deadline", ""), assignment.get("difficulty", ""), round(assignment.get("score", 0), 2), "Done" if assignment.get("completed", False) else "Not Done" ] print("{:<5} {:<20} {:<15} {:<12} {:<15} {:<8} {:<10}".format(*row)) def show_study_summary(assignments): total_assignments = len(assignments) if assignments is not None else 0 completed_count = 0 incomplete_count = 0 for assignment in assignments: if assignment.get("completed"): completed_count = completed_count + 1 else: incomplete_count = incomplete_count + 1 if total_assignments == 0: completion_rate = 0 else: completion_rate = round((completed_count / total_assignments) * 100, 2) print("Total assignments:", total_assignments) print("Completed:", completed_count) print("Incomplete:", incomplete_count) print(f"Completion rate: {completion_rate}%")

📖 Key Parts Explained

Filtering Functions (view_order_by_undone, view_order_by_done, view_order_all)

All three work similarly: load all assignments, filter by completion status, then sort by score. The lambda function tells Python to sort by the "score" field. reverse=True puts the highest scores first (most urgent first).

view_assignments() — Table Display

Prints assignments as a formatted table. The format specifiers like {:<20} mean "left-align in a 20-character wide column". This creates neat, aligned columns.

"Done" if completed else "Not Done" — A ternary expression that converts the boolean completed field into readable text.

show_study_summary()

Counts completed vs incomplete assignments and calculates the completion percentage. Handles the edge case of zero assignments (to avoid division by zero).
