📄 test_delete.py

📁 StudySmart/tests/delete/test_delete.py

🔍 What does this file do?

This file contains a unit test for the delete_assignment() function. It verifies that when a user selects an assignment to delete, that assignment is actually removed from the database. It uses monkeypatch to simulate user input and a test database to avoid modifying real data.

🧪 Testing Concepts Used

monkeypatch — A pytest feature that replaces built-in functions temporarily. Here it replaces input() so the test doesn't need a real user typing. Instead, the test provides a pre-set answer "1" to simulate choosing the first assignment.

test_assignments_db — A special test database imported from config4test.py. This ensures tests never touch the real user data. See config4test.py for details.

assert — Checks if a condition is true. If not, the test fails immediately. Here it checks that the assignment count is 0 after deletion.

📝 Full Source Code

from src.core.delete.assignment import delete_assignment import pytest from src.data_processing_module.config4test import test_assignments_db as Assignments def test_delete_assignment(monkeypatch): # Create a mock assignment to delete mock_assignment = { "id": 1, "title": "Test Assignment", "description": "This is a test assignment.", "priority": 1, "status": "undone" } # Save the mock assignment to the Assignments Assignments.save({"last_id": 1, "assignments": [mock_assignment]}) # Call the delete_assignment function inputs = ["1"] # Simulate user input for assignment number to delete with monkeypatch.context() as m: m.setattr('builtins.input', lambda _: inputs.pop(0)) delete_assignment(Assignments=Assignments, assignments=Assignments.all("assignments")) # Verify that the assignment has been deleted assignments = Assignments.all("assignments") assert len(assignments) == 0

📖 Line-by-Line Explanation

Lines 1-3: Imports

from src.core.delete.assignment import delete_assignment — Imports the delete function we want to test. This is the function defined in delete/assignment.py.

import pytest — Imports the pytest testing framework, needed for monkeypatch.

from src.data_processing_module.config4test import test_assignments_db as Assignments — Imports the test database (not the real one!) and renames it to Assignments for convenience. This is critical — it means our test never touches real user data.

Lines 5-14: Creating a Mock Assignment

def test_delete_assignment(monkeypatch): — Defines the test function. pytest discovers any function whose name starts with test_.

mock_assignment = { ... } — Creates a dictionary that looks like a real assignment. It has an id of 1, a title, description, priority level 1, and status "undone". This is what we'll delete in the test.

Line 17: Saving the Mock Data

Assignments.save({"last_id": 1, "assignments": [mock_assignment]}) — Saves the mock assignment into the test database. The save() method writes JSON to the test file. After this line, the test database contains exactly 1 assignment with id=1.

Lines 20-23: Simulating User Input with monkeypatch

inputs = ["1"] — Creates a list with one value: the string "1". This simulates a user typing "1" when asked which assignment to delete.

monkeypatch.context() — Opens a temporary context where we can replace built-in functions. When the context exits, everything is restored.

m.setattr('builtins.input', lambda _: inputs.pop(0)) — Replaces Python's input() function with a lambda that pops from our inputs list. So when delete_assignment() calls input(), it gets "1" instead of waiting for user typing.

Line 24: Running the Function Under Test

delete_assignment(Assignments=Assignments, assignments=Assignments.all("assignments")) — Calls the actual delete function with our test database. It passes:
• Assignments — the test LangaDB instance
• assignments — the current list (which has 1 item)
Inside this function, it will show the assignments, get input "1" (from monkeypatch), find the assignment with id=1, and delete it.

Lines 27-28: Verification (Assert)

assignments = Assignments.all("assignments") — Fetches the current list of assignments from the test database after deletion.

assert len(assignments) == 0 — The most important line! It checks that the assignments list is now empty. If the delete function worked correctly, there should be 0 assignments left. If this assertion fails, pytest reports a test failure.

⚠️ Important Note

This test relies on the delete() method existing in LangaDB. However, looking at the LangaDB source code in controllers.py, the delete() method is not explicitly defined. The delete_assignment() function in assignment.py calls Assignments.delete(), which means this feature may not work as expected. This is a known incomplete feature in the project.

💡 How to Run This Test

From the project root directory, run:

pytest tests/delete/test_delete.py -v

The -v flag makes pytest show verbose output with the test name and result.
