📁 StudySmart/src/core/authentication/controllers.py

🔍 What does this file do?

This file handles user authentication — the process of signing up new users, logging in existing users, and logging out. It uses SHA-256 hashing to encrypt passwords before saving them, so passwords are never stored in plain text.

⚠️ NOT USED: This code is not actively used in the main application flow. Authentication functionality is currently disabled.

📝 Full Source Code

from src.data_processing_module.config import Users import hashlib from .session import load_session, save_session, clear_session def SignUp(Users=Users, test=None): username = input("What is your name: ") password = input("Password: ") password = str(hashlib.sha256(password.encode()).hexdigest()) user = Users.find("users", "username", username) if user: return False # User already exists Users.add("users", {"username":username, "password":password}) if load_session(test=test) == None: save_session(username, test=test) return True else: return False def LogIn(Users=Users, test=None): username = input("What is your name: ") password = input("Password: ") user = Users.find("users", "username", username) password = str(hashlib.sha256(password.encode()).hexdigest()) if user and user["password"] and password == user["password"]: if load_session(Users=Users, test=test) == None: save_session(username, test=test) return True else: return False else: return False def LogOut(Users=Users, test=None): clear_session(Users=Users, test=test) return True

📖 Line-by-Line Explanation

Lines 1-3: Imports

from src.data_processing_module.config import Users import hashlib from .session import load_session, save_session, clear_session

→ Users — The user database instance from config.py

→ hashlib — Python's built-in library for hashing (encrypting) data. Used to convert passwords into unreadable hash strings.

→ .session — Imports functions from the session.py file in the same folder (the . means "current folder"). These handle saving/loading login sessions.

Lines 5-14: SignUp() Function

def SignUp(Users=Users, test=None): username = input("What is your name: ") password = input("Password: ") password = str(hashlib.sha256(password.encode()).hexdigest())

→ def SignUp(Users=Users, test=None): — Defines the SignUp function. It has two parameters with default values: Users defaults to the real database, and test defaults to None (meaning not a test).

→ input("What is your name: ") — Asks the user to type their username.

→ hashlib.sha256(password.encode()).hexdigest() — This is the password encryption: password.encode() converts the text to bytes, sha256() creates the hash, and hexdigest() converts it to a readable string. This means the password is never stored as plain text.

Example: If password is "mypass123", after hashing it becomes something like "ef92b778bafe771e89245b89ecbc08a44a4e166c06659911881f383d4473e94f".

→ Users.find("users", "username", username) — Checks if this username already exists.

→ If user already exists: returns False (signup failed).

→ If new user: saves them to the database with Users.add(), then saves a session (auto-login) and returns True.

Lines 16-28: LogIn() Function

Similar to SignUp but checks existing credentials:

1. Asks for username and password

2. Hashes the entered password (same algorithm)

3. Looks up the user in the database

4. Compares the hashed password with what's stored

5. If match: saves session and returns True

6. If no match: returns False

Security note: This is why hashing is important — even if someone reads the JSON file, they can't see the actual passwords, only the hash strings.

Lines 30-32: LogOut() Function

def LogOut(Users=Users, test=None): clear_session(Users=Users, test=test) return True

The simplest function — it just clears the session file (empties it), which means "no one is logged in anymore". Always returns True because clearing a file rarely fails.
