📦 Installation Guide

Detailed instructions to install and configure StudySmart on your computer.

📋 System Requirements

Before installing, make sure you have:

→ Python 3.9 or higher — StudySmart works with Python versions 3.9, 3.10, 3.11, 3.12, and 3.13

→ pip — Python's package installer (comes with Python)

→ git — To download the project from GitHub

→ Terminal / Command Prompt — To run commands

💡 How to check your Python version

Open your terminal and type:

python --version

You should see something like Python 3.12.0. If it says "command not found", you need to install Python from python.org.

Step 1: Download the Project

You have two options to get StudySmart on your computer:

Option A: Download from GitHub (Full Version with Tests, CI, ...)

Use this if you want the complete project with version history and development structure.

# Clone the repository git clone https://github.com/THE-HEIST/StudySmart.git # Enter the project directory cd StudySmart

This creates a folder called StudySmart on your computer containing all the project files.

Option B: Run from the ZIP File (Just Using Version)

Use this if you just want to run the application quickly without Git.

→ Download the provided ZIP file and extract it to a folder on your computer.

→ Open a terminal in the extracted StudySmart folder.

Step 2: Create a Virtual Environment (Recommended)

A virtual environment keeps your project's libraries separate from other Python projects on your computer.

# Create a virtual environment named "venv" python -m venv venv # Activate the virtual environment # On Windows: venv\Scripts\activate # On Mac/Linux: source venv/bin/activate

After activating, you will see (venv) at the beginning of your terminal prompt. This means you are now working inside the virtual environment.

Step 3: Install Dependencies

StudySmart needs these Python packages to run:

pip install -r requirements.txt

This command reads the requirements.txt file and installs:

→ pytest — A testing framework to run unit tests

→ pytest-cov — Measures how much of your code is covered by tests

→ requests — A library for making HTTP requests

Step 4: Run the Application

You have two ways to start StudySmart:

Option A: Native Python File

Start StudySmart with:

python main.py

You should see the welcome screen. If you see an error, check the Troubleshooting section below.

Option B: Jupyter Notebook File

Start StudySmart by opening the main.ipynb in Anaconda Navigator or other Notebook editor and run the main cell.

Step 5: Run the Tests (Optional)

To verify everything is working correctly, run the test suite:

# Run all tests pytest # Run tests with coverage report pytest --cov=src # Run a specific test file pytest tests/create/test_assignment.py

All tests should pass (show green checkmarks). If any test fails, check your Python version.

🔧 Troubleshooting

Problem: "python not found"

Solution: Make sure Python 3.9+ is installed and added to your PATH. Try python3 instead of python on Mac/Linux.

Problem: "ModuleNotFoundError: No module named 'src'"

Solution: Make sure you are in the project root directory (the folder that contains main.py). Run cd StudySmart first.

Problem: "pip install" fails

Solution: Update pip first with pip install --upgrade pip, then try again.

⭐ Note

The ZIP file contains the complete project files required to run StudySmart. The GitHub repository provides the same project with its version history and development structure. For a quick demonstration, the ZIP version can be used directly without cloning the repository.

📁 Project File Structure

After installation, your project folder should look like this:
