📄 calculate_priority.py

📁 StudySmart/src/core/common/calculate_priority.py

🔍 What does this file do?

This is the brain of the priority system. It contains three functions that work together to determine how urgent each assignment is. The system considers two factors: difficulty (1-5) and days remaining until the deadline. The harder the assignment and the closer the deadline, the higher the priority.

📝 Full Source Code

from datetime import datetime, timedelta def calculate_priority_score(assignment): difficulty = int(assignment["difficulty"]) date_now = datetime.now().date() days_remaining = int((datetime.strptime(assignment['deadline'], "%Y-%m-%d").date() - date_now).days) if days_remaining <= 0: priority_score = 99999 else: priority_score = difficulty / (days_remaining + 1) return priority_score def get_priority_level(priority_score): if priority_score == 99999: priority_level = "OVERDUE" elif priority_score >= 2: priority_level = "HIGH" elif priority_score < 1: priority_level = "LOW" else: priority_level = "MEDIUM" return priority_level def re_calculate_priority(assignments): for assignment in assignments: priority_score = calculate_priority_score(assignment) priority_level = get_priority_level(priority_score) assignment["score"] = priority_score assignment["level"] = priority_level return assignments

📖 Line-by-Line Explanation

Line 1: Import datetime

from datetime import datetime, timedelta

Imports Python's date/time tools. datetime gives us the current date and can parse date strings. timedelta represents a duration (difference between dates).

Lines 3-12: calculate_priority_score()

def calculate_priority_score(assignment): difficulty = int(assignment["difficulty"]) date_now = datetime.now().date() days_remaining = int((datetime.strptime(assignment['deadline'], "%Y-%m-%d").date() - date_now).days) if days_remaining <= 0: priority_score = 99999 else: priority_score = difficulty / (days_remaining + 1) return priority_score

This is the core algorithm. Step by step:

→ difficulty = int(assignment["difficulty"]) — Gets the difficulty level (1-5) from the assignment dictionary and converts it to an integer.

→ date_now = datetime.now().date() — Gets today's date.

→ datetime.strptime(assignment['deadline'], "%Y-%m-%d").date() — Converts the deadline string (like "2026-09-15") into a date object. The format %Y-%m-%d means: 4-digit year, 2-digit month, 2-digit day.

→ (deadline - date_now).days — Subtracts today from the deadline to get the number of days left.

→ If days remaining ≤ 0: score = 99999 (a huge number to mark it as OVERDUE)

→ Otherwise: score = difficulty / (days_remaining + 1)

The +1 in the denominator prevents division by zero when the deadline is tomorrow (1 day left).

Examples:

• Difficulty 4, 2 days left → 4/(2+1) = 1.33 → MEDIUM

• Difficulty 5, 1 day left → 5/(1+1) = 2.5 → HIGH

• Difficulty 1, 10 days left → 1/(10+1) = 0.09 → LOW

Lines 14-22: get_priority_level()

Converts a numeric score into a human-readable label:

→ 99999 → "OVERDUE" (deadline has passed)

→ ≥ 2 → "HIGH" (urgent — do this first!)

→ 1 to 2 → "MEDIUM" (moderate urgency)

→ < 1 → "LOW" (still have plenty of time)

Lines 24-29: re_calculate_priority()

Updates all assignments with fresh scores. Called every time the program starts (in product.py's check_priority_new_day()) to ensure scores reflect the current date. Without this, yesterday's scores would be stale.
