🔍 What does this file do?

Tests the calculate_priority_score() function to verify the mathematical formula produces correct scores. Uses pytest.approx() for floating-point comparison.

📝 Test Data & Assertions

Test Data Setup

assignment = [{ "id": 1, "deadline": str(datetime.now().date() + timedelta(days=2)), "difficulty": 4, ... },{ "id": 2, "deadline": str(datetime.now().date() + timedelta(days=2)), "difficulty": 2, ... }]

Two test assignments, both due 2 days from now, but with different difficulties (4 and 2). Using datetime.now().date() + timedelta(days=2) creates a dynamic deadline that's always 2 days in the future, regardless of when the test runs.

test_calculate_priority

def test_calculate_priority(): assert calculate_priority_score(assignment[1]) == pytest.approx(2/3) assert calculate_priority_score(assignment[0]) == pytest.approx(4/3)

Verifies the formula: score = difficulty / (days_remaining + 1)

→ Assignment 1: difficulty=4, days=2 → 4/(2+1) = 4/3 ≈ 1.33

→ Assignment 2: difficulty=2, days=2 → 2/(2+1) = 2/3 ≈ 0.67

pytest.approx() is used because floating-point math can have tiny rounding errors. It checks if values are "approximately" equal (within 0.0001).
