⚡ Quick Start

Get StudySmart running in under 3 minutes! Follow these 4 simple steps.

Step 1: Download the Project

You have two options to get StudySmart on your computer:

Option A: Download from GitHub (Full Version with Tests, CI, ...)

Use this if you want the complete project with version history and development structure.

# Download the project from GitHub git clone https://github.com/THE-HEIST/StudySmart.git # Move into the project folder cd StudySmart

What this does: The git clone command copies the entire project from GitHub (an online code storage) to your computer. After that, cd moves you into the project folder.

Option B: Run from the ZIP File (Just Using Version)

Use this if you just want to run the application quickly without Git.

→ Download the provided ZIP file and extract it to a folder on your computer.

→ Open a terminal in the extracted StudySmart folder.

Step 2: Install Python Dependencies

StudySmart needs a few extra Python packages to work. Install them with pip.

# Install all required libraries from requirements.txt pip install -r requirements.txt

What this does: The pip install -r requirements.txt command reads the requirements.txt file and automatically downloads and installs all the libraries listed there (pytest, pytest-cov, requests). Think of it like ordering supplies from a shopping list.

Step 3: Run the Application

You have two ways to start StudySmart:

Option A: Native Python File

Start StudySmart with:

# Start the StudySmart application python main.py

What this does: The python main.py command tells your computer to run the main.py file using the Python interpreter. This file is the "entry point" — the first file that runs when you start the program.

Option B: Jupyter Notebook File

Start StudySmart by opening the main.ipynb in Anaconda Navigator or other Notebook editor and run the main cell.

Step 4: Use the Application

Once the application starts, you will see a welcome screen and a menu like this:

******************** WELLCOME TO STUDYSMART ******************** No Function Name --------------------------------------------- 1 View Assignments 2 Add Assignment 3 Delete Assignment 4 Mark Assignment as Done 5 Undo Mark Assignment as Done 6 Show Study Summary 7 Clear Terminal 0 Exit Enter your choice:

What this does: The program shows you a numbered menu. Type a number and press Enter to choose an option. For example, type 2 to add a new assignment, or 1 to view all your assignments.

Example workflow:

# 1. Add your first assignment (choose option 2) Enter your choice: 2 Assignment name: Math Homework Module: Algebra Deadline (Ex: yyyy-mm-dd): 2026-09-15 Difficulty level (1 to 5): 3 # 2. View your assignments (choose option 1) Enter your choice: 1 Then choose: 3 (View All Assignments) # 3. Exit the program (choose option 0) Enter your choice: 0 Good Bye!

⭐ Note

The ZIP file contains the complete project files required to run StudySmart. The GitHub repository provides the same project with its version history and development structure. For a quick demonstration, the ZIP version can be used directly without cloning the repository.
